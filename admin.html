Sinkronisasi Otomatis via Google Apps Script

Aktifkan upload file Materi Ajar langsung dari form dan backup Excel (.xlsx) satu klik ke Google Drive.

Cara Aktivasi (2 Menit):
  1. Buka script.google.com lalu buat proyek baru.
  2. Salin isi google-drive-sync.gs dan tempelkan ke editor Apps Script.
  3. Klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  4. Salin URL /exec, tempel di atas, lalu klik Simpan & Tes.

🔔 Notifikasi WhatsApp Otomatis Deadline Project

Aturan Pengiriman: (1) Saat H-2, H-1, dan Hari-H deadline, siswa otomatis mendapat WA pengingat pukul 07:00 WIB. (2) Jika siswa belum lapor selesai melebihi deadline, sistem terus mengirim WA setiap hari pukul 07:00 WIB sampai siswa melapor selesai.

Cara Aktifkan 100% Otomatis: Daftar akun di fonnte.com → hubungkan WhatsApp sekolah → salin Token ke atas → pastikan google-drive-sync.gs versi terbaru sudah di-Deploy di Google Apps Script → klik Simpan & Pasang Jadwal 07:00. Setelah aktif, pengingat berjalan otomatis di server Google setiap jam 07:00 WIB walau komputer mati.
